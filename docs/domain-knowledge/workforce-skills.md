# 上门养老照护人员与专业技能

状态：domain knowledge 草案
日期：2026-05-13

本文整理上门养老照护场景中“服务人员”涉及的职业、资质、技能边界和服务项目映射。业务称呼上可以使用“服务人员”作为通称，不要把普通上门照护人员统称为“社工”。“社工”是社会工作专业角色，适用于资源链接、个案管理、心理社会支持等场景，不等同于养老护理员、长期照护师、护士或助老员。

## 1. 角色命名原则

| 术语 | 建议用法 | 原因 |
| --- | --- | --- |
| 服务人员 | 业务通用称呼 | 覆盖养老护理员、长期照护师、助老员、陪诊员、助浴员、护士等多类执行人员 |
| 养老护理员 | 生活照护和基础养老照护的专业工种 | 有国家职业技能标准，可用于理解技能等级和培训要求 |
| 健康照护师（长期照护师） | 长期照护专业角色 | 有 2024 年国家职业标准，更贴近长护险和长期照护服务场景 |
| 护士 | 医疗护理服务执行者 | 执业注册和医疗机构管理要求更强，适用于吸痰、换药、导尿等医疗护理服务 |
| 助老员/陪诊员/助浴员 | 地方或机构岗位/服务岗位 | 可作为岗位标签，不应替代资质判断 |
| 社会工作者/社工 | 社会工作专业服务角色 | 适合评估社会支持、链接资源、做个案跟进，不适合泛指一线护理执行人员 |

## 2. 主要资质和技能来源

| 类型 | 官方/行业基础 | 适合覆盖的服务 | 业务边界 |
| --- | --- | --- | --- |
| 养老护理员 | 《养老护理员国家职业技能标准（2019 年版）》 | 基本生活照料、清洁照护、饮食照护、排泄照护、睡眠照护、体位转移、安全防护、心理支持、部分基础照护 | 生活照护为主，不能自动覆盖医疗护理 |
| 健康照护师（长期照护师） | 《健康照护师（长期照护师）国家职业标准（2024 年版）》 | 长期照护计划下的生活照护、基础护理、应急处置、功能维护、对症护理、心理照护等 | 更贴近长期照护和失能照护，但仍需区分医疗行为 |
| 护士 | 《护士条例》《护士执业注册管理办法》及“互联网+护理服务”试点规则 | 上门医疗护理、延续性护理、换药、导管护理、吸痰、导尿、注射/输液等需按当地规范判断的项目 | 医疗护理应由具备执业资格且符合机构管理要求的人员执行 |
| 家政/助老服务人员 | 家政服务员等职业技能标准、地方服务商准入和机构培训 | 助洁、助餐、代办、陪同、非医疗生活支持 | 适合生活支持，不应承担医疗护理 |
| 社会工作者 | 社会工作者职业资格体系和民政/社区服务体系 | 需求评估、资源链接、家庭沟通、心理社会支持、困难救助衔接 | 属于社会工作专业支持，不是默认护理执行角色 |

## 3. 长护险 36 项服务的技能映射

以下映射用于业务理解。地方政策或机构协议有更严格要求时，应以当地规则为准。

| 服务组 | 典型项目 | 默认可执行角色 | 风险边界 |
| --- | --- | --- | --- |
| 进食饮水与营养支持 | 协助进食/水及指导、管饲饮食协助 | 养老护理员、长期照护师；管饲相关应提高资质要求 | 不做吞咽诊断，不调整医嘱或配方 |
| 排泄照护 | 协助排泄、失禁照护、人工取便、人工肛门/便袋清洁 | 养老护理员、长期照护师；人工取便/造口相关建议要求专项培训或护士参与 | 出血、疼痛、感染、造口异常必须升级 |
| 清洁照护 | 洗发、理发、口腔清洁、指/趾甲清洁、擦浴、沐浴、更衣、整理床单位 | 养老护理员、长期照护师、经培训助浴/助老服务人员 | 跌倒、皮肤破损、压疮、低血糖、意识异常需暂停并上报 |
| 体位与功能维护 | 体位管理、生活功能训练、翻身叩背排痰、压疮预防 | 养老护理员、长期照护师；康复训练建议康复治疗师/护士指导 | 不替代康复处方，不强行牵拉或负重训练 |
| 基础健康观察 | 协助给药、生命体征测量、安全防护及指导 | 养老护理员、长期照护师；异常值应升级给护士/医生/家属 | 不能擅自改药、加药、停药或解释诊断 |
| 医疗护理 | 吸痰、氧气吸入、常规换药、雾化吸入、灌肠、置管、导尿、快速血糖测定、物理降温、造口护理、气管切开护理、深静脉置管护理 | 注册护士或医疗机构派出的合规护理人员；部分项目按地方规则可由经培训人员协助 | 必须校验医疗机构、人员资质、操作授权、医疗废物和不良事件流程 |
| 认知/运动/吞咽/言语功能训练 | 认知功能训练、运动功能训练、吞咽功能训练、言语功能训练 | 长期照护师、养老护理员可执行日常维护性训练；专业治疗计划应由医护/康复/言语治疗专业人员制定 | 不做专业诊断，不替代治疗师评估 |

## 4. 与买单类型的关系

同一类服务人员可能参与多个买单类型下的服务，但不同买单方的准入和凭证要求不同。

| 买单类型 | 人员要求重点 | 凭证要求重点 |
| --- | --- | --- |
| 长护险 | 服务机构定点、服务人员资质、服务项目授权、当地经办规则 | 服务计划、服务项目、时长、确认、异常、纸单或电子记录 |
| 爱心卡/地方补贴 | 服务商白名单、一线人员培训、服务终端使用能力 | 订单、积分/卡码脸支付、服务确认、消费流水 |
| 商业护理险 | 保险合同认可的服务商或材料要求 | 保单、理赔触发条件、护理记录、费用材料 |
| 自费 | 平台准入、服务能力、用户确认 | 订单、服务完成确认、支付记录、评价/投诉 |

## 5. 术语和资质边界

- 业务文档优先使用“服务人员”作为通称，不把普通上门照护人员叫作“社工”。
- “社工”只在确实提供社会工作服务时出现，例如个案管理、困难救助、资源链接、家庭关系支持。
- 普通生活照护不应被包装成医疗服务。
- 医疗护理不应由普通助老员或未经授权的养老护理员执行。
- 不能把“会照顾老人”当成资质依据；应能说明人员接受过什么培训、具备什么证书或被授权执行哪些服务。
