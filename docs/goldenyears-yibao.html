金色年华的三大方法论

标准方法论
"标准现场化"
从"标准在纸上"到"标准在现场"
核心机制："标准即代码" + 现场实时反馈。

主管维护标准 → AI 自动生成督导/引导/评估规则 → 事前提示 → 事中引导/督导 → 事后评估。
监督方法论
"黑盒变白盒"
让每一次上门服务可感知、可验证、可审计
技术手段：多模态数据采集（雷达+录音+拍照+定位+声纹），AI 交叉矛盾检测验证，从原始数据到服务报告全程可审计。

质量方法论
"循环式改善"
机构内部管理 + 医保局监督，双驱动质量提升
核心理念：服务质量既不只是机构的事，也不只是医保局的事，而是双方共同的事。

微观服务过程监管 + 宏观服务质量监管 → 发现问题 → 机构提升 → 数据体现提升。

2产品设计

护工 — 移动端 App

两个 Tab：今日任务、标准规范。

Tab 1：今日任务
服务流程
1）发起任务
2）选择老人，显示老人基本信息（姓名/重点关注/地址）
3）勾选计划服务的项目（显示各项目剩余次数）
4）点击"发起"，弹出确认信息，GPS 定位验证 + 信标验证
5）验证通过，进入服务，显示录音界面，AI 实时引导/督导在后台运行
6）点击"结束服务"，拍照或从相册选择照片上传
7）结束服务，服务记录由 AI 自动生成
Tab 2：标准规范
内容
1）通用标准 — 适用于所有上门服务的通用行为规范和操作准则
2）长护险项目规范 — 按长护险服务项目分类的具体操作标准和 SOP
3）培训 Copilot — 具体功能待定（可能需要在站点运营 Dashboard 配套培训管理 Tab）

站点运营 — Dashboard

概览
Tab
首页总览（集团运营数据+质量数据）、服务人员、设备、长者、服务排期、进行中服务、已完成服务、回访管理、家属反馈、服务培训。
和现在版本有何不同
1）"设备"需要管理毫米波雷达。服务人员绑定设备，对应现实中雷达派发给护工的行为。
2）"服务人员"需要录入声纹信息。
3）在"长者"界面，要选择一名对应的服务人员；对应关系也显示在"服务人员"界面，即显示某一名服务人员对应服务哪几名长者。
4）"服务人员"界面需要管理登陆App的账号密码。
5）"服务排期"待了解现在做法
6）"进行中服务"显示所有实时发生的服务，展示基本的服务信息、可能的异常信息提示（GPS不符合、声纹不符合等）、查看实时语音转文字日志、查看实时毫米波雷达位置图、发起语音/视频飞检。
7）"已完成服务"显示所有已经完成的服务。展示：基本的服务信息、服务质量评估（AI评估的总结）、语音记录（原始音频+日志+AI解析信息）、雷达记录（雷达数据+加工统计后数据+AI解析信息）、检查信息（如果有飞检）、回访信息（如果存在对应服务的回访信息）。
8）回访管理：记录每一条回访记录。3种类型：上门回访、人工电话回访、AI电话回访。谁执行的回访、何时何地、回访的结论。
9）家属反馈：记录每一条反馈，包含：时间、谁的家属、对应服务人员、反馈内容、反馈渠道、针对反馈的措施记录。

医保局 — Dashboard（金色智眼）

概览
Tab
总览仪表盘、机构管理、服务审计、异常与预警、标准与合规、质量趋势。
功能说明
1）"总览仪表盘"全市核心指标（服务总量、经费支出、机构数量、覆盖老人数），跨机构质量排行和异常预警汇总。
2）"机构管理"定点机构列表，基本信息、服务规模、质量评分/评级。点击下钻到单个机构的详细指标。
3）"服务审计"按条件检索任意一次服务，查看完整审计视图（六重证据链+AI评估+关联回访/反馈）。支持随机抽查模式。
4）"异常与预警"AI 自动标记的异常服务列表，分类分级。跨服务模式识别（系统性异常检测）。处理流程追踪（待核实→已核实→已处理）。
5）"标准与合规"医保局发布的官方标准，各机构的执行合规率。跨机构横向对比同一标准的执行情况。
6）"质量趋势"跨机构多维度质量对比，单机构质量趋势（改善/恶化），机构自动评级（A/B/C/D）。
