# 金色年华 Demo 演示脚本

演示时长约 20-25 分钟。演示者需要在不同角色间切换，建议提前打开多个浏览器 tab。

---

## 准备工作

| Tab | URL / 入口 | 角色 |
|-----|-----------|------|
| Tab A | 登录为 site_operator | 站点主管（翠苑站） |
| Tab B | /careworker | 服务人员（张阿姨） |
| Tab C | /family | 家属（王女士） |
| Tab D | 登录为 org_admin | 总部管理员 |

---

## 第一部分：站点运营的基础准备

> 角色：**站点主管**（Tab A）
> 目标：展示站点开始运营前需要完成的基础数据准备工作

### 步骤 1：进入站点管理首页

- 登录后默认进入**首页**（HomeArea）
- 简要介绍 KPI 仪表盘：今日服务数、待排班缺口、待复核记录、全站平均服务质量分
- 说明："这是站点主管每天打开系统看到的第一个画面。我们先来做开站前的准备工作。"

### 步骤 2：录入服务人员

- 点击左侧导航 → **服务人员**（SocialWorkersArea）
- 展示现有人员列表，介绍字段：姓名、电话、资质、状态
- 点击 **+ 新增** → 填写一位服务人员信息（如"张阿姨"）
- 说明："每一位上门服务的护理员，都需要先在系统里建档。"

### 步骤 3：绑定智能工牌

- 点击左侧导航 → **设备管理**（SmartBadgesArea）
- 展示工牌列表，介绍状态：待激活、可用、使用中、离线、低电量
- 激活一个新工牌（输入设备编码）
- 将工牌绑定给刚才创建的"张阿姨"
- 说明："智能工牌是我们的核心硬件。服务人员佩戴它上门服务，工牌会自动录音、定位、记录服务过程。"

### 步骤 4：登记服务对象

- 点击左侧导航 → **服务对象**（ServiceObjectsArea）
- 展示现有服务对象列表，介绍字段：姓名、年龄、地址、参保类型、风险标签
- 点击 **+ 新增** → 填写一位老人信息（如"李爷爷，82岁，翠苑一区"）
- 设置参保类型（养护险）、添加护理备注（"糖尿病，忌甜食"）
- 说明："每位接受服务的老人都有完整档案，包括健康状况、护理注意事项、风险提示。"

### 步骤 5：创建服务计划

- 在李爷爷的详情页中 → 创建服务计划
- 使用 AI 辅助输入："每周一、三、五上午10点到12点，助餐+基础健康观察"
- 系统生成计划预览 → 确认
- 说明："服务计划可以手动填写，也可以用自然语言让 AI 帮你生成。系统会根据计划自动排期。"

### 步骤 6：查看服务排期

- 点击左侧导航 → **服务排期**（SchedulesArea）
- 切换日历视图，展示本周排期
- 找到刚才生成的排期记录，展示详情：日期、时间段、服务对象、服务项目
- 手动指派服务人员"张阿姨"
- 说明："排期生成后，站点主管可以查看日历总览，手动调配人员。如果有空缺，首页的'待排班缺口'KPI 会实时提醒。"

### 小结

> "到这里，站点的基础数据准备就完成了：人员建档、工牌绑定、老人登记、服务计划、排期指派。接下来我们看一次完整的上门服务是怎么进行的。"

---

## 第二部分：上门服务全程 + 站点后续工作

> 目标：展示一次完整的服务闭环——从服务人员出门到站点主管完成审核

### 步骤 7：服务人员出发（切换到 Tab B）

> 角色：**服务人员 张阿姨**（Tab B - /careworker）

- 进入护理员工作台
- 展示今日任务列表：时间、服务对象、地址、服务项目
- 点击"李爷爷"的任务 → 进入任务详情
- 介绍：服务对象信息、服务项目清单、注意事项（"糖尿病，忌甜食"）
- 说明："张阿姨在手机上看到今天的任务安排，点进去就能看到老人的详细情况和注意事项。"

### 步骤 8：查看 SOP 规范

- 在任务详情中 → 点击查看 SOP
- 展示标准操作流程文档（如"助餐服务规范"）
- 说明："每一项服务都有标准操作流程。如果是新手护理员，可以随时查阅确保服务质量。"

### 步骤 9：开始服务（模拟）

- 点击"开始服务" / 工牌连接模拟器
- 展示工牌状态：已连接、录音中
- 模拟完成服务清单：逐项勾选（助餐准备 -> 进食辅助 -> 餐后清理 -> 生命体征测量）
- 标记一项异常（如"老人今天食欲不好，进食量偏少"）
- 说明："工牌自动录音、GPS 定位。护理员按照清单完成每一项，遇到异常情况可以随时标记。"

### 步骤 10：完成服务

- 点击"完成服务"
- 系统自动记录：服务时长、位置轨迹、录音文件
- 展示服务完成确认页
- 说明："服务结束后，所有数据自动回传到系统。接下来我们切回站点主管，看看她那边收到了什么。"

### 步骤 11：站点主管审核记录（切换到 Tab A）

> 角色：**站点主管**（Tab A）

- 点击左侧导航 → **服务记录**（RecordsArea）
- 展示最新记录列表，找到张阿姨刚完成的服务记录
- 介绍筛选器：按日期、审核状态、导出状态
- 点击进入记录详情，展示：
  - 服务基本信息（时间、时长、参与者）
  - 服务项目完成清单（已完成/异常/未完成）
  - GPS 轨迹（到达/离开位置）
  - 录音回放 + AI 转写文本
  - 异常记录（"进食量偏少"）
- 说明："站点主管可以看到完整的服务证据链：工牌自动录音、GPS 证明到岗、AI 转写方便快速浏览、异常需要人工确认。"

### 步骤 12：处理异常 & 确认记录

- 查看异常记录"进食量偏少" → 标记为"已知晓，持续观察"
- 补充审核意见
- 确认记录 → 状态变为"可导出"
- 说明："每条记录都需要站点主管审核确认后才能导出。异常情况需要处理后才能关闭。"

### 步骤 13：家属收到推送（切换到 Tab C）

> 角色：**家属 王女士**（Tab C - /family）

- 如果是首次：展示家属绑定流程
  - 输入老人姓名、身份证号
  - 填写家属信息、关系
  - 设置推送频率（每日/每周/仅异常）
- 展示推送消息列表：
  - "李爷爷今日服务完成：助餐 + 健康观察"
  - "异常提醒：今日进食量偏少，护理员已记录"
- 说明："家属通过微信 H5 页面绑定后，可以实时收到服务通知。老人的每一次上门服务，家属都能知道。"

### 小结

> "这就是一次完整的服务闭环：张阿姨带着工牌上门 → 按规范完成服务 → 数据自动回传 → 站点主管审核确认 → 家属收到通知。整个过程有录音、有定位、有清单、有审核，全链路可追溯。"

## 第三部分：总部管理人员的日常管理

> 角色：**总部管理员**（Tab D）
> 目标：展示集团视角下的质量监控和规范管理

### 步骤 14：管理概览（质量仪表盘）

- 登录后默认进入**管理概览**（DashboardView）
- 介绍页面级控制器：站点选择（全部/单站点）、周/月切换
- 展示 4 个 KPI 卡片：
  - 本月平均服务质量分
  - 服务总次数 / 在岗人数
  - 质量提升 vs 下降人数
  - 家属订阅率 + 环比趋势
- 说明："总部可以一眼看到所有站点的运营状况，也可以切换到单个站点深入查看。"

### 步骤 15：员工服务质量排名

- 向下滚动 → 展示员工服务质量评分表
- 介绍 ABCD 评分体系：
  - A 分 = 服务对象评价（AI 基于录音分析）
  - B 分 = 家属评价
  - C 分 = SOP 符合度（AI 对照规范打分）
  - D 分 = 特殊识别（如表扬、投诉）
  - S 分 = 综合总分
- 点击某位员工 → 打开详情弹窗
  - 展示趋势折线图（最近 12 个周期的 S 分变化）
- 说明："ABCD 四维评分让质量评估更客观。其中 A 和 C 是 AI 自动评分，B 和 D 是人工/家属反馈。"

### 步骤 16：站点对比表

- 展示站点对比表：各站点的人员数、服务数、各项得分对比
- 说明："总部可以横向对比各站点的运营效率和服务质量，发现薄弱环节。"

### 步骤 17：规范管理（SOP）

- 点击第二个 tab → **规范管理**（SupervisorContent）
- 展示左侧目录结构：通用规范 / 各服务项目专属规范
- 点击一个文件夹（如"口腔清洁"） → 展示 SOP 文档
- 介绍双层视图：
  - **SOP 层**：标准操作流程文档（人工编写或 AI 辅助生成）
  - **AI 层**：切换到 AI 配置层
    - 展示两张卡片：监督规则（Supervision）和报告模板（Report）
    - 说明监督规则如何自动从 SOP 生成
- 说明："总部制定 SOP 规范后，AI 自动生成对应的实时监督规则和报告模板。前线护理员按 SOP 执行，AI 用监督规则自动打 C 分。"

### 步骤 18：AI Copilot 演示（可选）

- 在任意页面打开右侧 AI 助手面板
- 演示几个对话场景：
  - "帮我查看翠苑站本周服务质量排名"
  - "张阿姨最近的服务记录有异常吗"
  - "为'生命体征测量'生成一份新的 SOP"
- 说明："AI Copilot 贯穿整个系统，无论是站点主管还是总部管理员，都可以用自然语言和系统对话，快速完成查询和操作。"

### 小结

> "总部管理员通过质量仪表盘监控全局，通过 ABCD 评分体系量化服务质量，通过 SOP 规范管理确保标准统一，通过 AI 实现自动化评分和规则生成。"

## 演示注意事项

1. **数据准备**：确保各页面有足够的 mock 数据展示，避免空状态
2. **角色切换**：提前登录好 4 个 tab，切换时简要说明"现在我切换到 XX 角色"
3. **节奏控制**：每个步骤停留 1-2 分钟，重点步骤（步骤 11 服务记录详情、步骤 15 ABCD 评分）可以多花时间
4. **互动点**：步骤 5（AI 生成服务计划）和步骤 18（AI Copilot）是技术亮点，可以邀请客户提问
5. **备用方案**：如果 AI 功能不稳定，步骤 18 可以跳过，前 17 步已经是完整闭环
