Section 01

系统概述

GoldenYears 是一套录音驱动的社区养老上门服务管理系统。 社工佩戴智能工牌上门服务，按键开始录音，系统自动完成语音转写、AI 规整、 服务记录写入与语音反馈，无需社工手动填报。集团管理、站点运营、服务主管、 社工、服务对象家属五种角色均通过统一的聊天界面加角色专属 Tab 访问系统， 支持 Web 端与飞书端双入口。

核心数据流：
智能工牌录音 → 语音转写 → AI 规整（服务记录 + 对象档案 + 异常检测） → 语音反馈（TTS → 工牌蓝牙播放） → 多角色结构化查看（聊天 + Tab） → 周期报告（运营 / 家属） → 结算导出

七个模块

  • lak Session broker — lifecycle hooks、多 platform、CC session 调度
  • goldenyears-agent lak sidecar — AI 调度入口、角色上下文注入、录音规整调度
  • goldenyears-web 前端 SPA — React 聊天界面 + 角色 Tab，可嵌入飞书 H5
  • goldenyears-api 业务服务 — REST API、角色权限过滤、CRUD、报告聚合、导出
  • goldenyears-gateway 设备接入层 — 工牌 WSS 长连接、音频上下行、遥测上报
  • goldenyears-controller 工作流编排 — ASR 调度、TTS 调度、事件编排、定时任务
  • goldenyears-ops 运维配置 — 系统配置、用户管理、权限配置、监控

七个模块

lak
仓库: lak (已有)
Go

Session broker。维护与 Web / 飞书 / 其他 platform 的连接，调度 CC session 生命周期，执行 lifecycle hooks（scope_check、prepare_session、after_send、on_session_end）。不需要新仓库，在配置中添加一个 lumii-goldenyears project 指向 goldenyears-agent sidecar 即可。

lifecycle hooks 多 platform CC session broker
goldenyears-agent
仓库: lumii-goldenyears-agent
Go

lak sidecar，系统 AI 调度入口。实现角色上下文注入（prepare_session）、权限门控（scope_check）、录音规整调度（transcription_ready → POST /sessions/start → CC session → on_session_end → controller）。所有 AI 能力统一经过 lak/CC session。

sidecar scope_check prepare_session 录音规整
goldenyears-web
仓库: lumii-goldenyears-dashboard
TypeScript + React + Vite

前端 React SPA。聊天界面 + 角色相关 Tab（服务记录、待确认、排单、报告等）。可独立部署，也可作为飞书 bot 多 Tab H5 页面嵌入。通过 WebSocket 连接 lak，REST 调用 goldenyears-api。

React SPA 角色 Tab 飞书 H5 WebSocket
goldenyears-api
仓库: lumii-goldenyears-dashboard
TypeScript + Node.js + Express

业务 REST API 服务。所有数据访问的角色权限校验在此层强制执行。提供机构、人员、服务对象、任务、服务过程、报告、导出、审计等完整 CRUD 接口。与 goldenyears-web 共享同一仓库 lumii-goldenyears-dashboard。

REST API 角色权限 CRUD 报告聚合 导出
goldenyears-gateway
仓库: lumii-goldenyears-gateway
Go

纯 I/O 设备接入层。维护工牌 WSS 长连接（心跳、重连、认证），上行接收 Opus 音频分片并转发 controller，下行将 TTS 音频推送到指定工牌蓝牙耳机。不含业务逻辑，不调 ASR/TTS，不直接写 MySQL。

WSS 长连接 音频上下行 遥测上报 指令下发
goldenyears-controller
仓库: lumii-goldenyears-controller
Go

业务编排核心。主动连接 gateway WSS（内网连公网），驱动全部后台处理：阿里云实时 ASR 调度、TTS 调度 + Opus 压缩、录音事件编排（recording_started/stopped → transcription_ready → 通知 agent）、周期报告与数据清理定时任务。

ASR 调度 TTS 调度 事件编排 定时任务
goldenyears-ops
仓库: lumii-goldenyears-ops
TypeScript + Node.js

系统管理后台。纯运维，不跑业务逻辑。负责系统配置（ASR/TTS 参数、存储配置）、用户管理（角色分配、权限配置）、机构管理（开通、停用）、监控（设备在线率、ASR 成功率、存储用量）。

系统配置 用户管理 权限配置 监控

05权限三层防护

系统采用三层纵深防御机制，确保即使单层被绕过（如 prompt injection），数据仍不会泄露。

scope_check
lifecycle hook 级别。在消息路由到 CC 之前拦截。快速判断角色权限。
prepare_session
CC system prompt 注入角色上下文。CC 被告知只能查询哪些数据范围。
API 过滤
最终保障。GY_ACTOR_TOKEN 解析身份，SQL 层强制过滤。Prompt injection 无法绕过。
