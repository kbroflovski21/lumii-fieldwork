# 分角色 UI 设计

状态：分角色 UI 设计基线
日期：2026-05-13
仓库：`aro-network/lumii-fieldwork`

## 1. UI 框架

本文只定义角色、工作区和动作边界。全局视觉系统、产品壳、响应式和组件规则见 [`global-ui-guidance.md`](global-ui-guidance.md)。

本文对齐 [`agentic-flows.md`](agentic-flows.md)。每个角色进入后都是：

```text
聊天主界面
  + 当前角色相关工作区
```

聊天用于提问、查询、总结、解释、提醒和生成建议。

工作区用于展示结构化数据、记录明细、报告、订阅状态和可执行动作。

视觉规则不在本文里细化。所有角色页面必须套用 [`global-ui-guidance.md`](global-ui-guidance.md) 中定义的全局助手优先产品壳：桌面端 56px 图标导航栏、首页可用右侧高亮信息、手机端底部导航、全局玻璃质感、视觉变量和字体规则。

后台助手能力通过各角色的记录、报告、洞察、记录复核和订阅报告入口呈现。F05 自动规整和 F06 周期报告由这些入口承接。

## 2. Flow 对照

| 流程 | 主角色 | UI 承接 |
| --- | --- | --- |
| F01 运营激活智能工牌 | 站点运营 | 站点运营：设备 |
| F02 服务主管设置 SOP | 服务主管 | 服务主管：SOP |
| F03 运营排单 | 站点运营 | 站点运营：服务排期 |
| F04 服务人员上门记录服务 | 服务人员 | 服务人员：当前服务、历史记录 |
| F05 后台自动规整服务记录 | 后台助手 | 站点运营：服务记录 |
| F06 后台周期性生成洞察报告 | 后台助手 | 集团管理：报告；服务主管：SOP 调整；家属：订阅报告 |
| F07 家属订阅、实时查询和接收报告 | 服务对象家属 | 服务对象家属：服务与状态、订阅报告 |
| F08 运营导出服务日志用于结算 | 站点运营 | 站点运营：服务记录中的筛选和导出动作 |
| F09 运营和管理查看报告并主动查询 | 集团管理、站点运营、服务主管 | 各角色聊天入口和结构化工作区 |

## 3. 集团管理

默认聊天问题：

- 最近服务质量怎么样？
- 服务人员有没有按规程做？
- 哪些站点异常最多？
- 哪些服务对象需要重点关注？
- 家属订阅趋势怎么样？

工作区：

| 工作区 | 内容 |
| --- | --- |
| 运营总览 | 服务量、完成率、异常率、结算日志导出趋势 |
| 质量与规程 | SOP 完成率、漏项排行、服务中断、时长异常、异常未闭环、站点对比 |
| 对象与家属 | 服务对象状态变化、风险趋势、重点关注对象、家属订阅 |
| 报告 | 周报、月报、专题分析、导出管理报告 |

主要动作：

- 追问数据原因。
- 下钻到站点、服务人员、服务对象和服务记录。
- 查看服务对象风险和家属订阅趋势。
- 生成整改建议。
- 导出管理报告。

角色重点：

- 集团管理看跨站点趋势和管理报告；F08 结算服务日志由站点运营默认承接。

## 4. 站点运营

默认聊天问题：

- 今天有哪些服务？
- 哪些智能工牌离线或未同步？
- 哪些服务还没排期？
- 哪些服务记录需要复核？
- 哪些服务对象需要重点关注？
- 本月哪些服务日志可以导出结算？
- 查一下某个服务对象的健康档案和家属订阅。

工作区：

| 工作区 | 内容 |
| --- | --- |
| 首页 | 聊天入口、今日服务概览、待排服务、待复核记录、在线服务人员和工牌健康、推荐动作 |
| 人员 | 服务人员目录、联系方式、常用工牌关系和赞数 |
| 设备 | 智能工牌激活、站点归属、在线状态、电量、同步状态、丢失和停用管理 |
| 对象 | 健康档案、服务资格、地址展示、地图显示点、照护重点、风险标签、服务计划、计划例外、家属绑定和订阅状态 |
| 排期 | 服务计划生成的具体日程、按次服务、时间窗、服务人员分配、单次调整、清单 / 日历 / 地图视图 |
| 记录 | GPS 证据、原始音频、转写文本、结构化服务记录、复核状态、异常标记、导出状态和导出历史 |

主要动作：

- 新增和维护服务人员。
- 激活、停用、标记丢失和恢复智能工牌。
- 新增和维护服务对象、服务计划和计划例外。
- 创建按次服务并分配服务人员。
- 在清单、日历和地图视图中查看服务计划生成的具体日程和按次服务日程。
- 在服务记录中复核归属、补充信息和处理异常。
- 查询服务对象健康档案、服务安排和家属订阅。
- 按需导出服务日志用于结算。

服务记录内导出规则：

- 导出前必须展示筛选条件、字段范围、异常标记和未确认项。
- 导出后记录操作者、导出时间、筛选条件和文件版本。
- 存在待复核记录、未闭环异常或信息不完整时，必须提示先确认或带标记导出。

## 5. 服务主管

默认聊天问题：

- 这个服务项目 SOP 怎么设置？
- 哪些异常分支需要补进 SOP？
- 哪些 SOP 版本需要调整？

工作区：

| 工作区 | 内容 |
| --- | --- |
| SOP | 服务项目、步骤、必问项、异常分支、完成标准、版本和生效范围 |
| SOP 调整 | 后台汇总的漏项模式、异常分支触发、服务记录样本引用、调整建议、版本变更记录 |

主要动作：

- 设置或更新 SOP。
- 查看需要调整 SOP 的汇总证据。
- 调整 SOP 版本和生效范围。
- 发布 SOP 更新。

角色重点：

- 服务主管负责 SOP 定义、版本和调整；单条服务记录复核、记录退回和 F08 服务日志结算导出由站点运营承接。

## 6. 服务人员

默认聊天问题：

- 今天我要服务谁？
- 当前服务有什么注意事项？
- 我刚才的记录完整吗？

工作区：

| 工作区 | 内容 |
| --- | --- |
| 今日任务 | 可选排单产生的任务、地址、时间、注意事项 |
| 当前服务 | 工牌记录状态、开始时间、服务对象、对象注意事项、禁忌、上次异常、家属关注点、SOP 提醒、现场提示 |
| 历史记录 | 自己的服务记录、待补充事项、异常说明 |

主要动作：

- 查看今日任务。
- 查看当前服务提示和服务对象上下文。
- 按工牌开始和结束服务记录。
- 补充服务说明。
- 查看自己的服务记录。

说明：

- 最小使用方式支持服务人员只使用工牌按钮。
- 服务人员只要按工牌按钮开始和结束，后台也能生成服务记录。
- 没有排单时，服务人员仍可直接服务，后台按录音内容推断服务对象和服务项目。

## 7. 服务对象家属

入口：

- 小程序。
- 公众号。

默认聊天问题：

- 最近服务情况怎么样？
- 今天有没有上门服务？
- 家里老人状态有没有变化？
- 这周/月服务报告发我看一下。

工作区：

| 工作区 | 内容 |
| --- | --- |
| 服务与状态 | 最近服务状态、服务时间、服务摘要、状态变化、风险提示、后续关注事项 |
| 订阅报告 | 订阅状态、日报、周报、月报、推送记录 |

主要动作：

- 绑定服务对象并订阅小程序或公众号消息。
- 实时查询服务情况。
- 查看日报、周报和月报。
- 追问报告内容。

隐私边界：

- 家属只看脱敏服务摘要、服务时间、服务内容、状态变化和风险提示。
- 原始录音、原始转写、内部审核备注、服务人员绩效、后台置信度和机构内部处理记录属于机构内部资料。
